# 🚗 CarZone – Car Dealership Website

## 📌 Project Overview

CarZone is a Django-based car dealership website developed to help car business owners showcase their latest and featured cars online. It allows users to browse available vehicles, explore car details, search for cars, and filter vehicles based on different criteria.

The website provides a convenient platform for customers to discover cars and make enquiries about vehicles available for sale.

## ✨ Features

* **Latest Cars:** Browse recently added vehicles.
* **Featured Cars:** Explore highlighted cars listed by the dealer.
* **Car Search:** Search for cars based on user requirements.
* **Car Filtering:** Filter vehicles by model and price.
* **Car Details:** View information about individual vehicles.
* **Customer Enquiries:** Make enquiries about cars listed for sale.
* **Dealer Platform:** Provide car dealers with an online platform to showcase their inventory.

## 🛠️ Technologies Used

* **Backend:** Python, Django
* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Database:** PostgreSQL
* **Tools:** Visual Studio Code, Git, GitHub

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Akhila-282/carzone-prooject.git
```

### 2. Navigate to the Project

```bash
cd carzone-prooject
```

### 3. Create a Virtual Environment

```bash
python -m venv env
```

### 4. Activate Virtual Environment

Windows:

```bash
env\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure Database

Configure PostgreSQL database credentials in the Django settings file.

### 7. Apply Database Migrations

```bash
python manage.py migrate
```

### 8. Start the Development Server

```bash
python manage.py runserver
```

Open the application at:

`http://127.0.0.1:8000/`
